# P2.4 — Gemini Free-Tier Proxy Deployment

Architecture:

```text
Niko MAUI app → authenticated HTTPS Coach Proxy → Gemini API Free Tier
```

The mobile app has no Gemini SDK and no Gemini API key. The backend reads the
key only from its process environment. The proxy accepts only the approved
aggregate Coach context and applies the Core safety policy before returning a
response. The local deterministic Coach remains the offline fallback.

Required backend environment variables:

```text
GEMINI_API_KEY=<secret supplied by the deployment secret manager>
GEMINI_MODEL=gemini-3.5-flash-lite
GEMINI_API_BASE_URL=https://generativelanguage.googleapis.com/v1beta
GEMINI_TIMEOUT_SECONDS=8
GEMINI_BILLING_ENABLED=false
GEMINI_FREE_QUOTA_AVAILABLE=true
GEMINI_PROVIDER_HEALTHY=true
GEMINI_PROVIDER_PAID_ACCESS=false
GEMINI_PAID_FALLBACK_CONFIGURED=false
COACH_PROXY_SESSION_SECRET=<backend-only HMAC secret>
COACH_PROXY_RPM_LIMIT=3
COACH_PROXY_DAILY_LIMIT=50
```

Only the explicitly allow-listed free-tier models are accepted. The backend
does not choose another model when the configured model is unavailable. Billing
must remain disabled in the Google project; setting the local billing guard to
`true` makes the provider unavailable.

The proxy requires a short-lived HMAC session token in `X-Coach-Session`.
Tokens must be issued by the deployment's authenticated session system. The
backend never accepts an unauthenticated request or a long-lived shared token.
`GET /health` requires the same session and reports `AvailableFree` only when
the model, billing, quota, fallback, and provider-health checks all pass.

Example deployment commands, with secrets injected by the hosting platform:

```text
dotnet publish backend/Niko.CoachProxy/Niko.CoachProxy.csproj -c Release -o publish
dotnet publish backend/Niko.CoachProxy/Niko.CoachProxy.csproj -c Release
```

Do not put these values in `appsettings.json`, MAUI configuration, source
files, APK assets, command history, or logs. The MAUI proxy transport is
disabled unless a deployment supplies an HTTPS proxy URL, health URL, and
short-lived authenticated runtime session through a secure platform mechanism.
Without that mechanism,
the app remains local-only.

The mobile runtime variable is `COACH_PROXY_SESSION_TOKEN`; it must contain a
short-lived session issued by the deployment authentication system, never the
backend HMAC secret.

Free-tier quotas are model- and project-specific and include RPM, TPM, and RPD
limits. The proxy adds stricter per-client minute and daily budgets and maps
provider quota failures to the local fallback.
