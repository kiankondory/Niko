# Niko — Roadmap

This roadmap is directional. Major changes require user evidence, capacity review, and safety review.

## Phase 0 — Reliable foundation

- Shared solution and Core.
- Event model, local store, sync queue, and baseline tests.
- Resource-key localization, fallback, and RTL/LTR.
- Offline QuickLog for the three primary events.

## Phase 1 — Cessation experience

- Dashboard, milestones, Craving Battle, and opt-in notifications.
- Body Recovery and Savings with disclaimers and locale-aware formatting.
- Minimal wearable companions and widgets.

## Phase 2 — Insights and personalization

- Local/minimum-data Trigger Analysis.
- Opt-in AI Coach with guardrails, quality evaluation, and kill switch.
- Export/delete, accessibility audit, and security hardening.

## Phase 3 — Maturity

- Language expansion and native translation review.
- Stronger sync, privacy-safe observability, and multi-platform end-to-end tests.
- Staged releases with feature flags and rollback.
