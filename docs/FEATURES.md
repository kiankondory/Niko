# Niko — Product Features

## Core logging

- One-tap QuickLog: `Smoked`, `Resisted`, and `Craving`.
- Timestamp, source, optional context/intensity, and sync status.
- Controlled edit and delete flows with appropriate audit behavior.

## Cessation support

- Craving Battle: short breathing, delay, hydration, movement, and support-contact actions.
- Body Recovery: staged, non-diagnostic recovery information.
- Trigger Analysis: time, place, emotion, and situation patterns using minimum necessary data.
- AI Coach: personalized, explainable, opt-in, and disableable suggestions.

## Motivation and feedback

- Healthy gamification based on consistency and resistance, never shame.
- Economy/Savings using user-configured price and currency with approximate results.
- Progress dashboard, milestones, and understandable reports.

## Platform scope

Mobile provides the full experience. Wearables and widgets remain focused on QuickLog and immediate feedback to reduce cognitive load and exposed data.
