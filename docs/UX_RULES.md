# Niko — UX Rules

- QuickLog must require minimal interaction and work offline.
- Sync, success, and error states must use short, clear messages.
- Language, direction, units, and formatting come from localization settings.
- Design for RTL/LTR, long text, large fonts, contrast, screen readers, and reduced motion.
- Relapse and consumption logs must receive non-judgmental responses with a clear next step.
- Craving flow must provide an immediate action, an alternative action, and access to support.
- Notifications must be opt-in, schedulable, and non-shaming.
- Sensitive data must not appear on widgets or lock screens without explicit user choice.
- Every screen must define loading, empty, offline, and error states.
