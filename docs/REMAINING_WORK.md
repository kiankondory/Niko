# Niko — کارهای باقی‌مانده تا انتشار

> مسئولیت: فهرست اجرایی و قابل‌راستی‌آزمایی کارهای باقی‌ماندهٔ محصول.
> وابستگی‌ها و لایه: اسناد محصول، Core، Infrastructure و MAUI؛ هیچ دادهٔ کاربر یا فایل `sources/` در این فهرست تغییر نمی‌کند.
> نکات و قیود: اولویت با پایداری، حریم خصوصی، آفلاین‌بودن، ترجمهٔ واقعی و تأیید دستی روی Galaxy A50 است.

## اولویت ۱ — پایداری و پذیرش دستی

- [ ] اجرای دستی نسخهٔ فعلی روی Galaxy A50 و ثبت نتیجهٔ startup.
- [ ] بررسی مسیرهای Dashboard، QuickLog، Battle، Island، Settings/Privacy و Widget.
- [ ] تست export، لغو تأیید دستگاه، تأیید دستگاه و Clear Data بدون ازبین‌رفتن ناخواستهٔ داده.
- [ ] تست onboarding پس از نصب تازه و پس از بازگردانی/پاک‌سازی داده.
- [ ] بررسی cold-start و ثبت زمان قابل‌قبول پس از Splash.
- [ ] بررسی دستی RTL/LTR، اندازهٔ فونت و حالت Light/Dark.

## اولویت ۲ — زبان‌ها و قالب‌بندی

- [ ] تکمیل ترجمهٔ native برای `de`, `es`, `fr`, `hi`, `id`, `ja`, `ko`, `pt-BR`, `ru`, `tr`, `uk`, `zh-Hant`.
- [ ] بازبینی انسانی متن‌های فارسی، عربی، چینی ساده و زبان‌های تکمیل‌شده.
- [ ] تست تغییر زبان بدون restart و بدون تغییر دادهٔ دامنه.
- [ ] تست فرمت عدد، تاریخ، درصد، واحد پول و جهت صفحه برای همهٔ localeها.
- [ ] فقط پس از پوشش کامل، تغییر metadata زبان‌ها به «کامل».

## اولویت ۳ — تجربه و دسترس‌پذیری

- [ ] تکمیل motion سبک و احترام کامل به Reduced Motion.
- [ ] بررسی VoiceOver/TalkBack، کنتراست، اندازهٔ لمس و متن‌های طولانی.
- [ ] بررسی نهایی طراحی Dashboard، QuickLog، Battle، Island، Settings و Widget.
- [ ] تکمیل بازخورد دیداری عملیات Widget و جلوگیری از لمس تکراری.

## اولویت ۴ — انتشار

- [ ] تعیین نسخه و release signing.
- [ ] تولید Store assets، توضیحات محصول و Privacy Policy نهایی.
- [ ] تولید APK/AAB معتبر با مسیر Visual Studio و ثبت checksum.
- [ ] static secret scan و مرور dependency/license/security.
- [ ] ساخت rollback plan و feature flags برای قابلیت‌های پرریسک.

## قابلیت‌های عمداً فریز یا اختیاری

- [ ] Wear OS فقط پس از در دسترس‌بودن ساعت و انجام تست واقعی Phone ↔ Wear.
- [ ] External Coach فقط با Proxy امن و تأیید free-tier؛ Local Coach همیشه پیش‌فرض و آفلاین باقی می‌ماند.
- [ ] Cloud sync/backup تا زمان تصمیم محصول و طراحی threat model اضافه نشود.
