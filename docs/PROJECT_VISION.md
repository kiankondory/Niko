# Niko — Product Vision

Niko is a reliable, privacy-first companion for nicotine cessation. It helps users understand patterns, survive cravings, and build sustainable behavior without shame or judgment.

## Product principles

- Logging consumption or resistance must be fast, clear, and available offline.
- Users own their data and control sharing.
- Progress reflects real behavior, not only perfect streaks.
- Mobile, wearable, and widget experiences must feel connected and low-friction.
- AI must be supportive, transparent, optional, disableable, and non-diagnostic.

## Success criterion

A user can log an event within seconds, understand triggers, take a useful action during a craving, and continue safely without losing data when offline.
